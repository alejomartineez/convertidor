# Convertidor de archivos

Agrega **«Convertir a»** al menú del click derecho de Windows para convertir archivos sin usar páginas web:

- **Imágenes**: PNG, JPG, WEBP, HEIC (iPhone), AVIF, GIF, BMP, TIFF, ICO, PSD, SVG
- **PDF**: a Word, a imágenes o a texto
- **Documentos**: Word, Excel, PowerPoint, TXT y HTML, a PDF y entre sí
- **Audio y video**: MP3, WAV, FLAC, M4A, MP4, MKV, MOV, WEBM, GIF animado…
- **Comprimir** imágenes, PDF y videos
- **Unir** varias fotos y PDFs en un solo PDF

## Descargar

**[Convertidor-Setup.exe](https://github.com/alejomartineez/convertidor/releases/latest/download/Convertidor-Setup.exe)** (Windows 10/11)

Si Windows muestra «Windows protegió tu PC», elegí **Más información → Ejecutar de todas formas**.

En Windows 11 la opción aparece dentro de **«Mostrar más opciones»** (o con Mayús + click derecho).

El programa se actualiza solo cuando sale una versión nueva.
